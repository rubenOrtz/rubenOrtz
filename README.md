## 🏛️ Professional Profile

Mi enfoque combina el rigor de la ingeniería industrial con la agilidad del desarrollo moderno de software.

- 🔭 **Current Focus:** Liderando el ecosistema [Electrics-App](https://github.com/rubenOrtz/Electrics-App), una Super-App para la legalización y cálculo de instalaciones de Alta y Baja Tensión.
- 🧪 **Expertise:** Arquitectura Limpia (Clean Arch), Sistemas Offline-First, y Automatización de normativas técnicas mediante IA.
- 🤖 **Innovation:** Implementación de agentes de IA para la generación procedimental de bibliotecas de componentes industriales.
